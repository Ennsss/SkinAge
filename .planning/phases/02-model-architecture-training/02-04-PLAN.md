Create `EarlyStopping` and `SkinAgeTrainer` in `SkinAge/src/models/trainer.py`.

**EarlyStopping class:**
- Constructor: `patience: int = 7`, `min_delta: float = 0.0`
- `__call__(val_loss) -> bool`: Returns True if improved (signal to save checkpoint), False otherwise. Sets `self.should_stop = True` after `patience` epochs without improvement.
- Attributes: `best_loss`, `counter`, `should_stop`

**SkinAgeTrainer class:**

Constructor parameters:
- `model: SkinAgeModel`
- `criterion: MultiTaskLoss`
- `config: dict` (full model_config.yaml dict)
- `device: torch.device`
- `output_dir: str = "outputs"` (for checkpoints and logs)

Key methods:

`train(train_loader, val_loader) -> dict`:
- Runs Phase 1 then Phase 2. Returns training history dict.

`_train_phase1(train_loader, val_loader) -> dict`:
- Call `self.model.freeze_backbone()`
- Create AdamW optimizer with LR=config.training.phase1.learning_rate, weight_decay=config.optimizer.weight_decay, filtering for params with requires_grad only
- Train for config.training.phase1.epochs (3)
- Each epoch: call `_train_epoch()` then `_validate_epoch()`
- Log per-head losses each epoch
- CRITICAL: Before each training epoch, call `self.model.train()`. The backbone's overridden `train()` method will keep encoder in eval mode while frozen.

`_train_phase2(train_loader, val_loader) -> dict`:
- Call `self.model.unfreeze_backbone()`
- Create NEW AdamW optimizer (fresh momentum buffers) with LR=config.training.phase2.learning_rate, weight_decay=config.optimizer.weight_decay, ALL model parameters
- Create CosineAnnealingLR scheduler with T_max=config.training.phase2.epochs, eta_min=config.training.phase2.lr_scheduler.eta_min
- Create EarlyStopping with patience=config.early_stopping.patience
- Train for up to config.training.phase2.epochs (30)
- Each epoch: train_epoch, validate_epoch, scheduler.step(), early_stopping check
- Save best checkpoint when validation loss improves
- Break if early_stopping.should_stop

`_train_epoch(loader, optimizer, scaler) -> dict`:
- Mixed precision: `torch.amp.autocast(device_type='cuda')` (or 'cpu' if no GPU)
- For each batch:
  - Extract image, heatmaps, quality_scores, age, age_indices from batch dict
  - NOTE on mixed batch composition: The collate_fn produces batches that naturally contain both age-labeled and age-unlabeled samples. The `age_indices` tensor identifies which samples have age labels. The trainer does NOT need to construct mixed batches manually -- this is handled by the DataLoader/collate_fn. Verify by logging `age_indices.numel()` vs batch size in the first epoch to confirm mixed composition.
  - Forward pass under autocast
  - Compute loss via criterion
  - scaler.scale(loss).backward()
  - scaler.step(optimizer)
  - scaler.update()
  - optimizer.zero_grad()
- Accumulate and return epoch-averaged loss dict
- On the first batch of the first epoch, log: `f"Batch composition: {len(age_indices)}/{batch_size} samples have age labels"` to confirm mixed batches are working correctly.

`_validate_epoch(loader) -> dict`:
- `torch.no_grad()`, model.eval()
- Same forward + loss computation, no backward
- Return epoch-averaged loss dict

`_save_checkpoint(epoch, val_loss, path)`:
- Save dict with: model_state_dict, epoch, val_loss, config
- Use `torch.save()`

`_log_epoch(phase_name, epoch, train_losses, val_losses)`:
- Print formatted epoch summary with all loss components
- Append to self.history list for later plotting

Use `tqdm` for batch progress bars within epochs.

Use `torch.amp.GradScaler('cuda')` for mixed precision. If device is CPU, skip scaler (use a no-op pattern or check device type).

Store training history as a list of dicts: `[{epoch, phase, train_total, train_heatmap, train_quality, train_age, val_total, val_heatmap, val_quality, val_age, lr}, ...]` for convergence monitoring.

Save history to `{output_dir}/training_history.json` at the end of training.

Create `SkinAge/scripts/train.py` as the CLI entry point for training.

Use argparse with arguments:
- `--config` (default: `SkinAge/config/model_config.yaml`) -- path to model config
- `--data-dir` (default: `data`) -- root directory for data files
- `--splits-dir` (default: `data/splits`) -- directory containing train/val/test split CSVs
- `--output-dir` (default: `outputs`) -- where to save checkpoints and logs
- `--seed` (default: 42) -- random seed
- `--device` (default: auto-detect via get_device())

Main flow:
1. Parse args
2. Load config from YAML
3. Call `set_seed(args.seed)` from reproducibility module
4. Call `get_device()` or use `args.device`
5. Load train/val splits using `load_splits(args.splits_dir)` -- returns train_df, val_df, test_df
6. Create train and val DataLoaders using `build_dataloader()` from dataset.py with:
   - train: `get_train_transforms()`, shuffle=True
   - val: `get_val_transforms()`, shuffle=False
   - batch_size and num_workers from config['dataloader']
   - `collate_fn=skinage_collate_fn` (already handled by build_dataloader)
7. Create SkinAgeModel from config, move to device
8. Create MultiTaskLoss using `MultiTaskLoss(**config['loss_weights'])` -- this works because constructor params are `heatmap`, `quality`, `age` matching config keys (see Plan 02-03)
9. Create SkinAgeTrainer(model, criterion, config, device, output_dir)
10. Call `trainer.train(train_loader, val_loader)`
11. Print summary: total epochs, best val loss, checkpoint path

Add `if __name__ == "__main__":` guard.
