Build the EfficientNet-B2 backbone wrapper and U-Net decoder for the SkinAge multi-task model.

Purpose: These are the two spatial-feature components of the architecture. The backbone extracts features at multiple scales; the decoder reconstructs 4-channel heatmaps from those features via skip connections.

Output: Two modules -- `SkinAgeBackbone` (returns intermediate features + 1408-dim pooled vector) and `UNetDecoder` (returns 512x512x4 heatmaps).
</objective>

<task type="auto">
  <name>Task 2: U-Net Decoder with Skip Connections</name>
  <files>SkinAge/src/models/unet_decoder.py</files>
  <action>
Create `DecoderBlock(nn.Module)` and `UNetDecoder(nn.Module)` in `SkinAge/src/models/unet_decoder.py`.

DecoderBlock architecture:
- `nn.Upsample(scale_factor=2, mode='bilinear', align_corners=False)`
- Before concatenation, add a safety interpolate: `x = F.interpolate(x, size=skip.shape[2:])` if spatial dims don't match (handles rounding edge cases per research pitfall #1).
- `nn.Conv2d(in_channels + skip_channels, out_channels, 3, padding=1, bias=False)` -> `nn.BatchNorm2d` -> `nn.ReLU(inplace=True)`
- Second conv: `nn.Conv2d(out_channels, out_channels, 3, padding=1, bias=False)` -> `nn.BatchNorm2d` -> `nn.ReLU(inplace=True)`

UNetDecoder architecture:
- Constructor takes `encoder_channels: list[int]` (default [16, 24, 48, 120, 352]), `decoder_channels: list[int]` (default [256, 128, 64, 32]), `num_classes: int` (default 4).
- 4 DecoderBlocks following the channel plan from research:
  - Block 0: in=352, skip=120, out=256 (16x16 -> 32x32)
  - Block 1: in=256, skip=48, out=128 (32x32 -> 64x64)
  - Block 2: in=128, skip=24, out=64 (64x64 -> 128x128)
  - Block 3: in=64, skip=16, out=32 (128x128 -> 256x256)
- Final: `nn.Upsample(scale_factor=2)` -> `nn.Conv2d(32, num_classes, 1)` -> `nn.Sigmoid()` (256x256 -> 512x512)

Forward pass:
- Takes `features` list (5 tensors from backbone encoder)
- Uses features[-1] as starting point (352 ch @ 16x16)
- Reverses features[:-1] for skip connections [120@32, 48@64, 24@128, 16@256]
- Returns tensor of shape (B, 4, 512, 512) with values in [0, 1]

Add a `verify_architecture()` classmethod that creates a decoder, feeds dummy features matching backbone output shapes, and asserts output is (1, 4, 512, 512).
  </action>

Expected: No errors. Output shape is (1, 4, 512, 512).
  </verify>
