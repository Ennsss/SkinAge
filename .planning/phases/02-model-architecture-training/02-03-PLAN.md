<task type="auto">
  <name>Task 2: Multi-Task Loss with Mixed-Label Handling</name>
  <files>SkinAge/src/models/losses.py</files>
  <action>
Create `MultiTaskLoss(nn.Module)` in `SkinAge/src/models/losses.py`.

Constructor parameters -- use names matching config['loss_weights'] keys so that `MultiTaskLoss(**config['loss_weights'])` works directly:
- `heatmap: float = 1.0`
- `quality: float = 2.0`
- `age: float = 1.5`

Store as `self.w_heatmap`, `self.w_quality`, `self.w_age` internally for clarity, but the constructor parameter names MUST be `heatmap`, `quality`, `age` to match the YAML keys. This ensures `MultiTaskLoss(**config['loss_weights'])` works without key mapping.

Loss components:
- Heatmap loss: `nn.MSELoss()` -- compares predicted heatmaps (B,4,512,512) vs ground truth
- Quality loss: `nn.HuberLoss(delta=1.0)` -- compares predicted quality (B,28) vs ground truth, both in [0,1] range
- Age loss: `nn.HuberLoss(delta=1.0)` -- compares predicted age vs ground truth, ONLY for samples with age labels

Forward signature:
```python
def forward(self, pred_heatmaps, pred_quality, pred_age,
            gt_heatmaps, gt_quality, gt_age, age_indices):
```

Mixed-label handling (CRITICAL):
- `age_indices` is a LongTensor from the collate function. If `age_indices.numel() > 0` and `gt_age is not None`, compute age loss on `pred_age[age_indices]` vs `gt_age`.
- If no age samples in batch, use `torch.tensor(0.0, device=pred_heatmaps.device)` with NO gradient (prevents NaN gradients per research pitfall #4).

Return: `(total_loss, loss_dict)` where:
- `total_loss` = self.w_heatmap * heatmap_loss + self.w_quality * quality_loss + self.w_age * age_loss
- `loss_dict` = `{'heatmap_loss': float, 'quality_loss': float, 'age_loss': float, 'total_loss': float}`

Also create a standalone `build_criterion(config: dict) -> MultiTaskLoss` factory function that reads weights from config['loss_weights']. Implementation: `return MultiTaskLoss(**config['loss_weights'])`. This works because the constructor param names (`heatmap`, `quality`, `age`) match the config keys exactly.
