  <action>
Create `QualityHead(nn.Module)` in `SkinAge/src/models/quality_head.py`.

Constructor parameters:
- `in_features: int = 1408` (from backbone GAP)
- `hidden_features: int = 512`
- `out_features: int = 28` (7 zones x 4 concerns)
- `dropout: float = 0.3`

Architecture:
- `nn.Linear(in_features, hidden_features)`
- `nn.BatchNorm1d(hidden_features)`
- `nn.ReLU(inplace=True)`
- `nn.Dropout(dropout)`
- `nn.Linear(hidden_features, out_features)`
- `nn.Sigmoid()` -- outputs in [0, 1] range

IMPORTANT — sigmoid_x_100 clarification: The config says `activation: sigmoid_x_100` but this is a description of the INFERENCE behavior. During training, the model outputs raw sigmoid [0, 1] because the dataset normalizes quality scores to [0, 1] and the loss operates in [0, 1] space. The x100 scaling (to get human-readable 0-100 scores) is applied ONLY at inference time, NOT in the model forward pass. Do NOT multiply by 100 in the QualityHead module.

Forward pass: takes (B, 1408) -> returns (B, 28) in [0, 1].
